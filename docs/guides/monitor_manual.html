第一部分：入门教程 · 班长的第一单教务闭环

用 5 分钟走通一次“看公私分区首页 → 处理一条紧急代课待办 → 回看经办记录”的完整流程。

1.1 登录并认识“上公下私”首页

  1. 登录 Dream 后默认进入 【首页】（底部第 1 个图标）。
  2. 如果你同时也是自己孩子的家长，首页已经自动把“公事”和“私事”分成上下两块，互不串扰：
    • 上半区（教务工作）：第 1 行是班长 4 个常用快捷入口，紧接着是一条精简的教务概览条，直接显示你名下的所辖学员、所辖教师、负责小班数量，右侧有 [ 进入教务中心 ]。
    • 下半区（自家孩子）：第 2 行是家长快捷入口，下方只展示自家孩子的上课与续费提醒，不会混入外部学员。

1.2 进入【教务中心】处理第一条紧急待办

  1. 点击首页教务概览条右侧的 [ 进入教务中心 ]，或点击底部第 3 个图标 【教务中心】。
  2. 顶部有 8 个功能入口，其中需要及时处理的入口（今日调度、购课续费、退款管理、周转账单）在有待办时右上角会亮小红点。
  3. 往下看待办列表，排在最顶部的浅红色紧急卡片就是最急迫的事项（如“老师请假待代课”）：点击 [ 指派代课 ] 直达原任老师周课表对应课格，从系统按“曾教过该学员 → 价位匹配 → 本周排课较少”排好序的列表中选一位空闲老师确认即可。
  4. 回到 【教务中心】，点击第 2 行最右侧的 【📜 经办记录】，即可回看刚才操作的这笔只读留痕。

第二部分：日常实操指南

按班长高频业务场景拆解具体操作与注意事项。

2.1 学员管理与排课（档案、买 4 排 4、换上课学员）

  • 查看与维护所辖学员（教务中心 →【👥 所辖学员】）：支持按姓名或家长手机号搜索，点开档案抽屉查看剩余未排课次、已排待上课程、在学课件（最多 6 个）、学员备注与档案修改记录；可在试课详情中协助输入家长注册邮箱完成绑定认领。
  • 新购固定位“买 4 排 4”批量排课：从待办卡进入排课工作台，先选定目标老师，系统同时校验接下来连续 4 周同一时段是否都空闲，确认后一键锁定 4 周固定位。
  • 老师课表空闲格直接代约：点开老师周课表点击绿色“约”单元格，可为已购课学员代约 1～4 节连课（自动提醒学员是否撞课）。
  • 更换实际上课学员（仅限 1 对 1）：在周课表点击已排课格选择 【换上课学员】，按规范英文名检索并选中新学员即可（无需同一家庭；原购课单付款家长与资金归属不变）。

2.2 老师团队与小班主理

管理负责老师（教务中心 →【👨‍🏫 负责老师】）

  • 新建与维护资料：新建老师并维护中英简介、风采相册、试讲视频及 ClassIn 二维码（老师端不可自改）。
  • 调时段与休假：在周课表帮老师批量加开时段、锁定时段、代请假或标记长期休假。
  • 办理离职：系统强制校验未来临时课、未来固定位、负责小班三项全部清零后才可办结。

主理小班课（教务中心 →【🏫 主理小班】）

  • 建班与委任：创建小班后可委任全平台在职老师执教（未绑老师前阻断购课排课），日常管理学员进退班与 4 周排期。
  • 暂停待排：仅停某 1 节时选择【暂停待排】，课次退回小班池择期补排。
  • 提前结课解散 / 归档：停办或离职时点【提前结课解散】作废未来课次并终止小班购课单；轮次完结账清后点【归档小班】。

2.3 购课录单、续费协商与课次清退

  • 线下收款与录单（教务中心 →【📋 购课续费】）：1 对 1 固定位必选价位、意向老师可不选；1 对 1 临时课支持 1～500 积分任意小额充入家长积分账户（同一家长同一时刻只能由 1 位班长持有，原余额为 0 可直接接管，大于 0 需先移交）；小班课核实到账后点 【确认收款】 锁定收款人。
  • 跟进 1 对 1 到期自动续费单：最后一周周一 08:30 自动生成并预占原位。若家长点【申请调整】，该单在待办置顶并标出 家长申请调整，可在确认收款前点 【修改购课单】 或 【标为已沟通】；若家长点【暂不续费】或开课前 24 小时未付，自动作废并释放预占。
  • 课次与自由积分清退（教务中心 →【↩️ 退款管理】）：仅可清退尚未排上日程的待排课次或自由积分余额；仅限当前资金持有人本人（对应班长）操作（管理员紧急兜底代退须传 1～5 张退款截图凭证），全部清退后原单转为已退费。

2.4 日常调课、今日调度与突发请假代课

  • 【📅 今日调度】同屏看全局：按“今天 / 明天 / 后天”日维度同屏查看所辖所有老师与当日课表，适合高峰期集中救场。
  • 指派/撤销代课：周课表抽屉点【指派代课】按熟客、价位与负荷筛选空闲老师（小班需连续 1 小时双格空闲，无人可代可【暂停待排】）；开课前可点【撤销代课指派】。
  • 请假退期待排 & 同师挪位（班长不锁 3 小时）：不足 3 小时弹出温和确认并显示学员近 30 天临期变动次数，可选【通融退回待排期】或【按学员旷课扣 1 节】；同师挪位自动高亮空闲绿格并置灰撞课格。
  • 考勤异常与回退补生：正常课次次日凌晨 02:00 自动结课；爽约可标【学员旷课】或【老师旷课】（误标可在周结算前纠偏）；已自动结课但实际未上（且未进已确认转账单）可在危险区点 【异常未上课回退补生】 作废并补生 1 节新课次。

2.5 周转账单、积分移交与名下托管资产（教务中心 →【💰 周转账单】）

  1. 周转账单：每周一凌晨 03:30 自动把上周已结课且收款人为你的课次打包生成草稿单；线下打款后点 【去上交并打款】 上传 1～5 张截图凭证提交（若被管理员驳回，保留明细退回草稿重交）。
  2. 积分移交：家长更换服务班长且积分余额大于 0 时，原班长在学员档案或【积分移交】页签点 【整体移交积分】 传凭证提交，新班长在待办确认收到后改绑持有人；在途已排临时课仍归原班长（若请假退回则退成 1 节绑定原班长的待排临时课次）。
  3. 托管资产：在【托管资产】页签随时盘点由你持有、尚未结课的自由积分余额、待排课次与已排未结课次（不含已结课课次），一键穿透去移交、清退或排课。

2.6 消息中心、沟通留言与经办记录

  • 消息中心（顶栏 🔔 铃铛）：点开卡片原地展开中英双语详情并自动消红点；暂不能处理时可点 [ 标为未读 ] 恢复警示提醒。
  • 学员备忘双权限：公开留言家长与老师均可见；内部备注仅老师、班长与管理员可见，适合写交接细节。
  • 经办记录（教务中心 →【📜 经办记录】）：班长经手的所有排课、代课、挪位、考勤与异常回退均按时间倒序永久留痕，支持按时间和类型筛选回查。

第三部分：核心业务流转图解

用通俗流程图展示与班长直接相关的 6 条核心业务主线，并拆解班长处理要点与各端协作提示。

3.1 购课、自动续费与退费流转

flowchart LR
    Start([家长买课 / 到期前7天自动续费]) --> Unpaid[待确认收款]
    Unpaid -->|家长申请调整| Adjust[协商调整中 · 保留预占]
    Adjust -->|班长改单或已沟通| Unpaid
    Unpaid -->|班长核实到账点确认收款| Paid[已收款 · 生成待排课次]
    Unpaid -->|班长作废 / 家长暂不续费 / 24h超时| Cancelled([已取消 · 释放预占])
    Paid -->|部分课次清退| Paid
    Paid -->|剩余课次全部清退| Refunded([已退费])
    Paid -->|小班提前结课解散| Terminated([已提前终止])

班长处理要点

收到线下转账后及时点【确认收款】生成待排课次并锁定收款人；遇到置顶的“家长申请调整”续费单，先沟通并在【修改购课单】调好再确认收款；放弃或退课则及时作废或清退。

联动影响与协作提示

续费单提前 7 天自动生成并预占原时段（老师课表显示橙色虚线“预”字，开课前 24 小时未付自动释放）；确认收款后立即转为正常排课。

3.2 约课、调课与上课结课流转

flowchart LR
    Pool[待排课次池] -->|班长批量排课 / 家长或班长约课| Class[已排定课程]
    Class -->|同师挪位 / 换上课学员 / 指派或撤销代课| Class
    Class -->|请假退回 / 撤排 / 小班暂停待排| Pool
    Pool -->|课次清退 / 小班解散| Void([已作废])
    Class -->|次日凌晨 02点 系统自动结课| Done([已结课 · 计入课酬与转账])
    Done -->|核实实际未上 · 异常回退补生| Pool

班长处理要点

负责 4 周买 4 排 4 或单节补排，以及请假退期待排、同师挪位、换上课学员与撤排；若自动结课后核实未上（且未进已确认转账单），在课格抽屉执行【异常未上课回退补生】。

联动影响与协作提示

已排课程次日凌晨 02:00 自动结课，老师下课无需手动点出勤，只需更新课件与备忘；家长自助请假需提前 24 小时、挪位需提前 3 小时，超时需联系班长。

3.3 老师请假与代课安排流转

flowchart TD
    Leave([老师或班长勾选 1~12 节提交请假]) --> Check{勾选的时段里有没有已排课？}
    Check -->|全是空闲时段| GreenToRed[空闲格直接变红不可约 · 老师可随时销假恢复]
    Check -->|包含已排课程| Alert[生成紧急代课待办 · 浅红卡片置顶通知班长]
    Alert --> Dispatch{班长如何调度？}
    Dispatch -->|找到合适老师| Sub[指派代课 · 原师蓝底SUB / 代课紫底代上]
    Dispatch -->|改走其他方案| Alt[退回待排期 / 同师平移 / 小班暂停待排]
    Dispatch -->|调度前原老师恢复| Revoke[原老师点销假恢复 · 待办自动撤销]
    Sub -->|开课前变动| CancelSub[班长撤销代课指派]
    Sub -->|次日凌晨 02点 自动结课| Finish([完成代课 · 课酬归代课老师])

班长处理要点

看到浅红紧急卡“老师请假待代课”，点【指派代课】直达原老师课格面板，结合原老师交接备注选空闲老师接手；该请假单下最后一节受影响课次调度完成后自动收口。

联动影响与协作提示

原老师请假不锁 3 小时入口，被代课格变蓝色 [SUB]（不计课酬），纯空闲格可随时点红色格销假；代课老师课表呈紫色 [代上] 并可见交接备注，授课后课酬 100% 计入本人周课酬单。

3.4 老师入职、休假与离职交接流转

flowchart LR
    New([班长或管理员新建老师]) --> Active[正常在职 · 可接约排课]
    Active -->|发起全天或跨周长假| OnLeave[长期休假 · 选课大厅暂不接新约]
    OnLeave -->|销假或期满恢复| Active
    Active -->|校验未来临时课/固定位/小班全部清零| Resigned([已离职 · 权限收回并下架])

负责新老师建档、维护中英简介/相册/ClassIn 二维码及处理长期休假；办理离职前必须把未来临时课、固定位和负责小班全部交接或清零。

联动影响与协作提示

简介、展示照片、试讲视频和二维码均由班长或管理员在后台维护，老师自己在【我的名片】看到的与家长端一致的只读预览。

3.5 小班开班、上课与解散归档流转

flowchart LR
    Create([主理人创建小班并委任老师]) --> Running[正常开班 · 招生排期与上课]
    Running -->|临时停某1节课| Pause[单节暂停待排 · 课次退回小班池]
    Pause --> Running
    Running -->|老师离职或停办| EarlyEnd([提前结课解散 · 作废未来课次与购课单])
    Running -->|轮次完结且账目结清| Archive([已归档 · 只读留存])

主理人处理要点

建班后及时委任执教老师，管理学员进退班与 4 周排期；小班老师请假时先筛全平台连续 1 小时双格空闲老师代课，无人可代再点【暂停待排】并在微信群通知家长。

联动影响与协作提示

小班课在课表固定占 1 小时（双倍高度），呈青绿色粗框并带 [G] 徽标和在读人数；系统筛选小班代课时自动过滤掉只空半小时的老师。

3.6 每周一收款归集与转账流转

flowchart LR
    Batch([每周一 03点30分 自动汇总上周已结课]) --> Draft[待核对草稿]
    Draft -->|班长核对明细 · 线下打款并传1~5张凭证| Reviewing[待管理员核验]
    Reviewing -->|管理员核验银行流水通过| Confirmed([已确认收款 · 资金归集完成])
    Reviewing -->|金额不符/凭证不清 · 附原因驳回| Draft
    Draft -->|班长作废重算 / 异常剔除归零| Void([已作废])

班长处理要点

每周一核对由你收款的已结课明细，线下转账后上传 1～5 张截图凭证提交；若被管理员驳回，保留原明细退回草稿，按驳回原因补充重交即可。

联动影响与协作提示

班长周转账单仅核算收款归集，不影响老师周课酬单生成，老师只需在本人【周课酬单】核对实际授课节数。

第五部分：核心规则解析

5.1 为什么“谁收款就由谁转账”，且不随代课或换学员改变？

家长线下转账并由你点击【确认收款】时，资金就已经进入你的账户。如果后续因为代课或换学员把账单归属转走，就会出现“钱还在你手里、账单却跑到别人名下”的混乱。因此无论谁代课或换谁上，最终都由收款班长在周一通过【周转账单】上交平台。

5.2 为什么班长操作不锁 3 小时，却要弹出提醒并显示学员近 30 天变动次数？

家长端限制 24 小时请假与 3 小时挪位是为防止随意爽约；而突发紧急情况需要班长拍板兜底。因此系统对班长完全放开时间门槛，只在不足 3 小时时温和提示并列出近 30 天临期变动次数，方便你判断该【通融退回】还是【按学员旷课扣 1 节】保护老师利益。

5.3 为什么【教务中心】不显示正常“待上课”？

班长名下每天有大量正常履约的待上课，若全部堆进教务中心会淹没真正急需救场的浅红代课与待审单据。正常待上课交给老师首页和各自课表承载，教务中心只聚焦“需要你做决定或经办的事”。
