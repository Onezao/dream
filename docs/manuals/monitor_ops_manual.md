# Dream 班长运营流程与规则手册 (Monitor Operations Manual)

> **适用对象**：中方教务班长（含兼任家长的班长）  
> **阅读说明**：本手册聚焦日常教务排班、收款录单、应急代课与每周资金归集的标准操作流程（SOP）与业务红线。全站 1 节标准 1v1 课次为 **30 分钟**（授课 25 分钟 + 课间缓冲 5 分钟）；小班课为 **50 分钟**（连续占用 2 个 30 分钟时段）。

---

## Quickstart：新班长 5 分钟入门速览

### 1. 记住“公私分明”三大Tab
很多班长自己也是家长，系统在一个账号内把“带学员”和“带自家娃”彻底分开：
- **首页**：第 1 行是教务高频入口（`线下录单`、`教务排课`、`今日调度`、`周转账单`），第 2 行是自家孩子家庭入口，下方是自家家庭信息流。
- **Tab 2【学员课表】**：**只看自家孩子**的本周课表，绝不会混入外部学员。
- **Tab 3【教务中心】**：**只管负责的外部学员、小班和老师团队**，绝不显示自家孩子数据；所有待排课、待续费、待退款、待转账待办全在这里处理。
- **Tab 4【我的】**：纯个人中心（自家多孩档案、个人账单、中英语言切换、改密），不包含任何对公教务单据。

### 2. 每天打开系统的 3 件事
1. **看红点与紧急卡片**：进入 Tab 3【教务中心】，优先处理顶部置顶的**浅红紧急卡**（老师请假待代课、固定位续费时段冲突）。
2. **盯紧待排与续费**：处理**浅黄提醒卡**（新购待排固定位、临期 72 小时续费预占单），防止黄金时段被释放。
3. **随手记备忘**：协助家长请假/挪课或更换上课学员后，顺手更新学员备注与在学课件进度，方便下一位代课或接手老师无缝衔接。

### 3. 每周一必做的 1 件事
- **周一 08:00 起**查收【周转账单】提醒，核对上周已结课由你代收的课次总额，在**周二审核前**完成线下打款并上传凭证，确保周三平台准时向老师发薪。

## 第二章：收款录单、价位与退费规则

### 2.1 老师“价位”体系（全端透明）
- **1v1 标准价位**：全平台统一由管理员维护价位字典，首期分为 **`16积分`**、**`18积分`**、**`21积分`** 三档（英文界面显示为 `16 Pts` / `18 Pts` / `21 Pts`），全端（含老师端）均可见。
- **班长权限边界**：班长录入或编辑老师时，只能从管理员已启用的价位字典中选择，**不能自行填写任意单价**。
- **小班课定价**：小班课（50 分钟）**不绑定老师 1v1 价位字典**，由创建/维护人在小班设置中单独填写单节积分售价与老师小班课酬。

### 2.2 购课录单（1v1 固定位 / 临时课 / 小班课）
1. **1v1 固定位（买 4 排 4）**：固定每周固定时间上课，4 周为一轮（通常每周 1~3 节，共 4~12 节）。录单后系统按老师当前最新价位自动核算总积分。
2. **1v1 临时课**：适用于短期加课或试听后单次买课（1~20 节），购买后进入待排池，家长或班长可提前 1~7 天自主约课。
3. **收款确认即生成课次**：班长线下收款后提交购课单并确认收款，系统即时生成对应数量的“待排期课次”，**资金持有人永久锁定为最初收款的你（班长）**，直到该课次结课并在下周一纳入周转账单归集。

### 2.3 调价与跨价位边界（红线必记）
- **老师调价后**：管理员调整某位老师的价位后，**已生成的购课单（包含已生成待付款的 72 小时续费预占单）系统内先不调整金额**，新生成的购课单才会按新价位计算。若需按新价位补齐差额，由班长与家长线下沟通补差。
- **跨价位换师**：同价位老师之间可直接平移固定位或换师（无差价）；若家长希望换到**不同价位**的老师，**系统内不支持线上补差价或退差价**，请先与家长线下协商差价，再在系统内协助调整或退旧买新。

### 2.4 核销退费规则
- **可退范围**：仅限状态为**“待排期”**的未上完课次可发起退费核销（周三平台发薪锁盘后的已结课课次物理冻结，不可退改）。
- **操作流程**：在【退款管理】选择目标学员与待退课次 $\rightarrow$ 填写退款备注与线下退款说明 $\rightarrow$ 提交核销。核销完成后对应待排课次即刻作废，避免家长继续约课。

## 第三章：怎么排课（分场景选工具 + 权限边界 + 续费 SOP）

### 3.1 排课权限与协作边界（先懂规矩）
- **全域开放，主责清晰**：系统已放开班长**全域排课与代课调配权限**——你不仅能给自己名下老师排课，也能帮全校其他老师排课或跨组指派代课。
- **日常主责**：平时优先维护并排满**自己负责的老师**（系统会在老师卡片上标出 **`我负责`** 徽标，方便一眼识别）。
- **跨组协作与代排救场**：遇到自己名下老师档期已满、或**其他班长忙不过来时帮忙代排/救急**，直接切换筛选条件即可给全平台其他班长名下的老师或学员排课。**无论谁经手排课，原收款班长的资金归属不变、授课老师课酬自动计入实际授课老师名下，不会串账。**

### 3.2 四大排课场景：该用哪个入口？
| 你的业务场景 | 推荐使用的入口 | 为什么用它 / 核心操作 |
| :--- | :--- | :--- |
| **场景 1：新学员还没定老师，要找人排【1v1 固定位】或【加约临时课】** | **【空闲大盘】**（首页 `教务排课` / 待办卡 `立即排课`） | 按 **价位（`16/18/21积分`）+ 时段（早/中/晚）** 一次看 5 位有空档的老师，直接排除没空老师，并自动校验固定位连续 4 周是否全通 |
| **场景 2：已经锁定某位老师（老生调时间、加临时课、查空档）** | **【负责老师】→ 老师 7 色周课表**（或从【所辖学员】穿透） | 目标明确时不用去大盘海选，直接打开该老师的 7 色周课表点 🟢 绿格，支持单约或连约 1~4 节 |
| **场景 3：当天或近 3 天突发急事（紧急代课、临时请假、当天救急排课）** | **【今日调度】**（首页 / Tab 3 第 1 行） | 聚焦昨天到未来 3 天（`[-1d, +3d]`），左侧看异常待办、右侧同屏对照当天有空的老师，1 秒指派代课或快搜老师/学员代办请假 |
| **场景 4：小班课排期与学员进退班** | **【主理小班】**（Tab 3 第 1 行） | 连续占用 2 格（50 分钟，冷青色 `[G]`），集中管理小班每周固定排期与在读学员进退班 |

### 3.3 实操一：从【空闲大盘】给学生找老师排固定位（买 4 排 4）
1. **带学员进入**：从 Tab 3 待办卡点击**【立即排课】**（自动带上该学员），或从首页点**【教务排课】**进入后先选定学员。
2. **筛选目标老师**：
   - 先选**价位**（与学员购课单一致，如 `16积分`）与期望**时段**（如 `晚 18-24`），系统自动隐藏完全没空的老师；
   - 列表优先展示 **`教过该学员`**（熟客）与 **`我负责`**（自己管辖）的老师，每张卡片右侧用横向小长方格直观展示整点空档。
3. **选老师并锁定 4 周**：点击老师卡片下的**【选取】**进入该老师的周排期确认页，选定每周固定时间（如每周二、四 18:00），系统自动执行**未来连续 4 周全通校验**；确认无冲突后一键生成 4 周 🟠 橙色固定位。

### 3.4 实操二：找固定老师微调 / 帮忙碌班长代排临时课
- **固定老师加课/微调**：进入 Tab 3【负责老师】，点开指定老师的 **7 色周课表**，点击任意 🟢【约】空白格，底部弹出抽屉，可选择 **单约 1 节（30分钟）** 或 **连约 2~4 节**（若后续连续格不足或学员余额不够，对应连约按钮会自动置灰提示）。
- **帮其他班长代排**：在【负责老师】把顶部筛选从 `我负责` 切为 `全部`（或在【所辖学员】中搜出目标学员进入课表），即可帮其他忙不过来的班长代约临时课或办理同师挪位，操作流水会完整记入你的【经办记录】方便对账追溯。

### 3.5 看懂 7+1 色周课表
| 颜色 | 状态含义 | 业务说明 |
| :--- | :--- | :--- |
| 🟠 **橙色** | **固定位** | 买 4 排 4 的固定位正课（最高优先级）；虚线边框带【预】字表示**续费预占（HOLD）** |
| 🟡 **黄色** | **临时课** | 提前 1~7 天抢约的临时正课 |
| 🔵 **蓝色** | **被代课** | 原老师请假，已指派其他老师代课（班长/家长/原老师视角为蓝色） |
| 🟣 **紫色** | **代上课** | 仅代课老师本人课表显示为紫色，代表替同事代课并计入本人课酬 |
| 🟢 **绿色** | **空闲可约** | 老师开放授课且未被占用的空档 |
| ⚪ **灰色** | **不可约** | 老师休息或已过期时段，显示“休” |
| 🔴 **红色** | **已请假** | 老师主动闭麦请假时段，显示“假” |
| 🟩 **冷青** | **小班课** | 连续占用 2 格（50 分钟），带 `[G]` 徽标与在读人数 |

### 3.6 固定位到期前 7 天自动续费与 72h 预占保护
- **每周一 08:30**：系统自动扫描处于固定位第 4 周（最后一周）的学员，自动生成下一轮待确认续费单，并在老师未来 4 周课表上打上**虚线橙色【预】字预占锁（HOLD）**。
- **排他保护**：从预占生效起（72 小时保护期），其他学员无法抢约该时段临时课，全力保护老生续费位。
- **班长跟进动作**：关注 Tab 3 的浅黄提醒卡（临期续费）或浅红紧急卡（如老师未来时段与小班/休息冲突），及时提醒家长确认付款；若家长确认不续，主动取消续费单释放时段。

## 第四章：请假、挪位、换人与应急代课

### 4.1 弹性请假与 `<3h` 温和提示
- 系统已取消“12.5% 请假配额”和“课前硬性锁死”，家长或老师临时有事均可随时在课表上操作请假（把已排课次释放回待排池）。
- **临期提示**：若距离开课 **不足 3 小时（`<3h`）** 操作请假、挪位或换人，系统会弹出温和确认提示框，确认后放行，但该次变动会记入《出勤异常记录》供周结对账透明查看。

### 4.2 更换实际上课学员（原转课场景）
- 若家长想把名下某节课让二宝或亲友孩子来上，**无需走退旧买新或复杂审批单**。
- 在课表点击对应课程卡片 $\rightarrow$ 选择**【更换实际上课学员】** $\rightarrow$ 选定目标学员即可。原购课单与资金归属保持不变，仅变更实际进班上课的学员档案与老师备忘关联对象。

### 4.3 今日调度与应急找代课
当老师临时请假时，Tab 3 顶部会出现**浅红紧急卡**：
1. 点击**【指派代课】**进入【今日调度】同屏对照视图。
2. 系统自动过滤出**在目标时段完全空闲 🟢 且具备对应课程资质**的在职老师，并按「曾教过该学员 → 同价位/相近价位 → 本周已排较少」智能排序。
3. 点击选定代课老师即可秒级完成换师：原老师课表变为 🔵 被代课，代课老师课表变为 🟣 代上课（课酬自动划归实际授课的代课老师）。

### 4.4 老师/班长离职交接红线
- **老师离职三防线**：办理老师离职前，系统强制校验其名下是否还有未上完的 **① 未来临时课、② 未来固定位、③ 主讲小班课**。必须全部协调代课、平移换师或更换小班主理人至清零后，才可确认离职；过往已结课课酬正常参与本周结算。
- **班长离职两防线**：解除班长职务前，必须先将名下托管的未结课次完成离职移交转账单，并将所辖老师与小班批量改绑给接手班长。

## 第五章：每周资金归集与转账对账

系统执行严格的**“周一出单、周二审核、周三发薪”**周度节律：
1. **周一 03:30**：系统自动汇总你名下上周（周一至周日）**所有实际已结课且由你代收款**的课次，预生成【周转账单】（若应转金额 $\le 0$ 则静默跳过）。
2. **周一 08:00**：系统向你发送待办提醒与邮件。你需要核对明细后，将对应款项**线下转账至平台账户**，并在周转账单内**上传打款凭证截图**提交审核。
3. **周二核算日**：平台管理员在后台核对凭证并确认收款。
4. **周三发薪日（红线提醒）**：平台周三统一向老师全额发放上周课酬。若你在**周二前未完成打款传凭证**，平台将先垫付老师工资，同时系统把你的账单标红记为逾期欠款并通知财务追缴。

> **重要**：只要课次在你的名下收款，无论这节课后来是换了其他老师代课、还是跨组排课，**资金归集责任始终锁定在你这里**，按实际结课进度纳入你的周转账单。

## 第六章：老师与学员档案日常维护

### 6.1 录入与维护老师档案
- **风采相册与主头像**：支持上传 1~6 张生活/教学照，支持拖拽排序，并可独立点选其中 1 张裁切为 `1:1` 主头像；删除主头像时系统自动将第一张顺位替补（至少保留 1 张）。
- **多媒体与建联**：上传 1~3 分钟 MP4 试讲视频（H.264 编码，≤ 50MB）、中英文自我介绍（各 ≤ 2000 字）及 ClassIn 好友二维码。
- **绑定价位**：从 `16积分` / `18积分` / `21积分` 中选择该老师对应的标准价位（每次修改档案关键字段均会写入审计日志）。

### 6.2 学员备注与在学课件更新
- 在【所辖学员】列表点击任意学员即可呼出综合档案抽屉，随时更新**在学课件/级别**与**家校备忘**。
- 老师请假时也可在请假抽屉中顺便补充该学员的最新课件进度与备注，便于代课老师第一时间掌握教学进度。

## Q&A：常见场景与异常处理速查

**Q1：家长想换一个更高或更低价位的老师（比如从 `16积分` 换到 `21积分`），系统里怎么操作？**  
A：系统内**不支持线上补差价或退差价**。同价位老师之间可以直接平移；跨价位调整需要你先和家长线下协商补/退差价，再在系统内协助退旧买新或调整排课。

**Q2：管理员刚把某位老师的价位从 `16积分` 调成 `18积分`，为什么系统自动生成的待续费单还是 `16积分`？**  
A：这是预期规则。老师调价后，**已生成的购课单（包含已生成的续费预占单）系统内先不自动改价**，只有之后新生成的单据才按新价位计价。如果这轮续费单需要按新价位结算，可以由你和家长线下补齐差额。

**Q3：某节课已经指派给其他老师代课了，最后结课后这笔钱该谁转给平台、课酬算谁的？**  
A：**财课分离、各算各账**：代收款项的**转账责任**依然归最初收款的班长，随班长周一的周转账单交给平台；但**上课课酬**100% 计入实际去上课的代课老师名下，原请假老师本节课酬为 0。

**Q4：小班课为什么在选老师价位时找不到对应价格？**  
A：小班课（50 分钟双格）不走 1v1 老师价位字典（`16/18/21积分`），而是由管理员/主理人在小班配置中**单独填写**小班单节售价积分与老师课酬。

**Q5：家长周三发薪锁盘后，才反馈上周某节课其实老师没上（系统自动结课了），还能在端内退回课次吗？**  
A：周三发薪锁盘后，已结算课次会被**物理锁定**，班长端无法直接退改或核销，请联系**平台管理员**在后台执行【异常结课回退】，由管理员核实后取消异常记录并自动为学员补回 1 节待排期课次。

**Q6：为什么我在 Tab 3 顶栏图标上只看到小红点，看不到具体待办数字？**  
A：为了避免图标被数字遮挡、并与下方筛选胶囊重复显示数字，系统规定只有强待办/审单类入口在有待处理事项时亮 `7px` 小红点；精确的待办条数统一在下方筛选胶囊（如 `排课 (3)`、`续费 (5)`）查看。

**Q7：新老师一直没空接单，或者我想临时找全校其他班长名下的老师代课，可以跨组约吗？**  
A：可以。系统已放开班长全域约课与代课调配权限，你在空闲大盘和今日调度中都可以看到全平台符合条件的老师（你本人负责的老师会标有 `我负责` 徽标方便区分）。

**Q8：为什么我自己的孩子周课表，在教务中心里搜不到？**  
A：这是系统的**公私物理隔离红线**。自家孩子的课表、买课与请假统一在首页家庭区与 **Tab 2【学员课表】** 操作，Tab 3【教务中心】只处理外部学员与老师团队事务，绝不混入个人家庭数据。
