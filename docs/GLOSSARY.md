### 4.1 通知业务标签受控字典 (Controlled Notification Tags)

为防止各业务模块自由造词导致 [M4 消息提醒](./prd/m4_notification.md) 标签语义漂移，全平台所有站内提醒卡片调用 M4 时**必须且只能从下表受控字典取值**（中英双语由前端对照字典展示，严禁私自新增或混用禁用同义词）：

| 标准中文标签 | 英文 UI 标签 (`vue-i18n`) | 淘汰 / 禁用同义词 | 适用业务场景边界 |
| :--- | :--- | :--- | :--- |
| **`[课程变动]`** | `[Course Change]` | `排课变更`、`课次变更`、`调课通知` | 1v1/小班排课落位、请假取消、同师挪位、代课指派/撤销、换人、小班提前解散或停课通知 |

| **`[续费提醒]`** | `[Renewal Notice]` | `续费催办`、`账单通知`、`预占作废` | 自动续费账单出具、临期二次催办、时段冲突待调解、替代作废及驳回假凭证原因告知 |

| **`[课酬对账]`** | `[Payout Notice]` | `发薪通知`、`周结提醒`、`工资单通知` | 老师每周课酬单草稿核对提醒、平台确认打款发薪告知及发薪附带警告提醒 |
| **`[教学协同]`** | `[Learning Sync]` | `课件变动`、`模板提醒`、`运营提醒` | 学员在学课件/级别变动推送、老师关闭常规可约模板影响提醒、小班连停催办归档与解散 |
