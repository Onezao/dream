## 1. 角色与身份 (Roles & Personas)

| 标准中文词 | 英文 UI (`vue-i18n`) | 底层 DB / 代码映射 | 淘汰 / 禁用词 | 语境与使用边界 |
| :--- | :--- | :--- | :--- | :--- |
| **管理员** | `Admin` | `admin` | 超管 | 平台最高运营与财务审核角色 |
| **班长** | `Monitor` | `monitors` | — | 通用角色身份、工作台名称及权限体系统一用**班长** |
| **小班主理人** | `Group Class Owner` | `classes.monitor_id` | — | **仅**在小班承包、小班归属、小班结算归集语境下使用，强调该班长对具体小班的经营权责 |
| **老师** | `Teacher` | `teachers` | 教师、外教 | 业务文案、原型与 UI 统一称**老师**（仅在说明国籍/母语属性时可补充“外籍老师”） |
| **代课老师** | `Substitute Teacher` | `substitute_teacher_id` | 代课教师、替课老师 | 临时顶替原定老师授课的老师 |
| **出资家长** | `Payer` | `payer_user_id` | 购课家长 | 涉及购课单创建、付款及资金/退款归属时精确使用**出资家长** |
| **家长** | `Parent` | `parent_user_id` | 监护人 | 通用家长身份、家长工作台、查看课表等泛指场景 |
| **学员** | `Student` | `student_profiles` | 学生（非 DB 表名语境） | 业务文案、档案卡片、课表筛选与 UI 统一称**学员** |

## 2. 核心实体与五大单据 (Core Entities & Documents)

| 标准中文词 | 简写 / 英文 UI | 底层 DB / 代码映射 | 淘汰 / 禁用词 | 语境与使用边界 |
| :--- | :--- | :--- | :--- | :--- |
| **课次** / **`TS`** | `TS` / `TimeSlot` | `time_slots` | 课节、课时 | 中文展示允许用**课次**或 **`TS`**；**数量统计单位统一用“节”**（如“剩余 8 节”） |
| **小班** | `Group Class`（代码 `GroupClass`） | `classes` | 班级（泛指班型时） | 多人固定班课实体统一称**小班** |
| **课件** | `Courseware` | `coursewares` | 教材、教案 | 教学内容与在学进度实体统一称**课件** |
| **购课单** | `CourseOrder` | `course_orders` | 订单（泛指时） | 家长购买或班长代录的正价/试课购课单据 |
| **续费单** | `RenewalOrder` | `AUTO_RENEWAL` | — | 1v1 固定位到期前 7 天自动预生成的待付款续费单 |
| **退款单** | `RefundOrder` | `refund_orders` | 退费单 | 剩余课次核销与线下退款记录单据 |
| **转账单** | `TransferOrder` | `transfer_orders` | 归集单 | 班长向平台归集待结算资金的周度单据 |
| **课酬单** | `PayStatement` | `weekly_settlements` | 周结单、发薪单 | 老师每周结课明细与平台发薪单据 |
| **其他盈余** | `Other Surplus` | `surplus_amount` | 小班盈余、盈余、利润 | 小班课程实收扣除老师课酬与平台抽成后的剩余归属金额；描述比例规则时可用**分成比例** |
| **打款凭证** | `Transfer Receipt` | `receipt_url` | 转账凭证、付款凭证、回执 | 班长线下向平台转账或平台发薪后上传的凭证截图 |
| **消息** | `Notification` | `notifications` | 站内信 | 端内消息中心（`/notifications`）列表条目统一称**消息** |
| **邮件通知** | `Email Notification` | `email_dispatches` | — | 关键业务事件触发的外部邮件送达 |

## 3. 核心业务动作 (Core Actions & Verbs)

| 标准中文词 | 简写（窄屏用） | 英文 UI | 淘汰 / 禁用词 | 语境与使用边界 |
| :--- | :--- | :--- | :--- | :--- |
| **排课** | 排课 | `Schedule` | 排班 | **供给侧 / 统筹侧**：老师开放可约时间槽、系统批量生成固定位周期 `TS`、或班长在调度看板统筹排定课表 |
| **约课** | 约课 | `Book` | — | **需求侧 / 权益侧**：家长或班长基于购课单剩余课次，为学员选定老师与时段进行预约占用 |
| **同师挪位** | **挪位** | `Reschedule` | 同师调课、调课 | 不更换授课老师，仅调整课次上课时间（空间受限的按钮/标签简写为**挪位**） |
| **代课** | 代课 | `Substitute` | 替课 | 不调整上课时间，仅更换实际授课老师 |
| **请假** | 请假 | `Leave` | — | 课前取消当次预约并退回权益池（或按规则处理出勤） |
| **结课** | 结课 | `Complete` | 完课 | 课次正常上课完成并进入可结算状态 |
| **核销** | 核销 | `Write-off` | 销课 | **仅**用于退款时对未排剩余课次进行资产清零销毁 |
| **结算** | 结算 | `Settle` | — | 系统每周定时算账并生成转账单与课酬单 |
| **打款** | 打款 | `Transfer` | — | 班长线下向平台账户转账（并上传打款凭证） |
| **发薪** | 发薪 | `Payout` | — | 平台管理员审核后向老师发放周度课酬 |
| **认领** | 认领 | `Claim` | 转正（作动作时） | 家长将班长代建的试课档案绑定至自己账号下 |
| **注销** / **归档** | 注销 / 归档 | `Archive` | — | 学员或老师档案永久停用并保留历史快照 |
| **停用** | 停用 | `Disable` | — | 可恢复的暂停接单或暂停状态 |
| **作废** | 作废 | `Void` | — | 购课单、续费单、转账单等单据失效 |
| **取消** / **撤销** | 取消 / 撤销 | `Cancel` / `Revoke` | — | 撤回已发起的排课、请假或代课指派 |

## 4. 页面、课型与状态词汇 (Pages, Lesson Types & States)

| 标准中文词 | 英文 UI / 标识 | 淘汰 / 禁用词 | 语境与使用边界 |
| :--- | :--- | :--- | :--- |
| **首页** | `Home` | 主页 | 各角色登录后的默认入口首屏（如家长首页、老师首页） |
| **工作台** | `Workspace` | — | 四个物理隔离的角色功能域（管理员/班长/家长/老师工作台） |
| **看板** | `Board` / `Grid` | — | 日历调度网格（如周调度看板、日应急调度看板） |
| **1v1** / **1vN** | `1v1` / `1vN` | 一对一、1对1、1对多、一对多 | 班型统一使用英文简写 `1v1`、`1vN` |
| **固定位** | `Fixed Slot` | 固定排课、周期课、常规课 | 每周固定星期与时段的周期排课位 |
| **临时课** | `Ad-hoc Lesson` | 加课 | 单次临时预约的课程 |
| **试课** | `Trial Lesson` | 试听课、体验课 | 新学员体验试听课程 |
| **待排** | `Unscheduled` | 未排 | 已购课尚未落位到具体时间槽的状态 |
| **预占 (`HOLD`)** | `HOLD` | 锁位、占座 | 续费单待付款期间对固定位 `TS` 的临时锁定状态 |
| **旷课** | `No-show` | 爽约 | 学员或老师未请假且未按时进入教室上课 |
| **定级** | `Level` | 等级、职级、星级 | 老师课酬与购课单价对应的级别 |
| **账号** | `Account` | 账户 | 系统登录凭证与身份主体 |
| **档案** | `Profile` | 资料 | 学员档案、老师档案 |
| **教室** | `Classroom` | 课堂、房间 | ClassIn 在线授课房间 |
