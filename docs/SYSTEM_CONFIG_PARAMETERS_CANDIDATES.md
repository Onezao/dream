## 1. 概述与用途说明

本清单系统性整理了 Dream 系统中所有涉及具体数值、时限阈值、比例比例及管控红线的业务参数。通过将这些参数从硬编码中剥离，未来可作为管理后台（Tab 4 `/admin/settings`）的动态配置项，供平台管理员根据不同学期阶段、大促活动或品控严格度进行灵活微调。

> [!NOTE]
> 本文档仅收录纯业务层面的待选参数定义与影响说明，不涉及数据库表设计、缓存实现或后端 API 代码等具体技术方案。

## 3. 一期优先动态配置清单（P0 · Top 5）

经产品确认，以下 **5 个业务最高频微调参数** 作为 **P0 首批接入管理后台（Tab 4 `/admin/settings`）** 的动态配置项；其余参数一期保持默认内置（随发版或环境变量维护）：

1. **`temp_booking_window_days`**（临时课可约时间窗，默认 `[1, 7]` 天）
2. **`parent_leave_cutoff_hours`**（家长端自助请假截止时限，默认 `24` 小时）
3. **`parent_reschedule_cutoff_hours`**（家长端自助挪位 / 换代课截止时限，默认 `3` 小时）
4. **`auto_renewal_overdue_cancel_hours`**（续费逾期自动作废提前小时数，默认 `24` 小时）
5. **`teacher_anomaly_alert_threshold`**（M5B 非常规出勤标红预警阈值，默认近 30 天 `>12.5%` 或 `>=4节`）
